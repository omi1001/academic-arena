1. Executive Summary & System Overview

Academic Arena is a gamified educational mobile and web platform built with React Native (Expo SDK 52, Expo Router v4), TypeScript, Node.js, Express, Firebase Auth, and Firebase Firestore database. The application enables students (Classes 6–12) to take single-player quiz runs, battle AI bots in 1v1 challenge matches, track real-time level progression, customize user profile aesthetics (avatar borders, title badges), compete on global/weekly leaderboards, earn UPI rewards, and manage content through a secure Admin Control Center.

Core Technology Stack

Frontend UI React Native, Expo SDK 52, Expo Router v4, TypeScript, React Native Reanimated Cross-platform UI components, screen routing, smooth animations, sound/haptic feedback.
State Management Zustand, AsyncStorage Client-side global state for authentication (authStore), user profile (userStore), and gameplay (gameStore).
API Layer Axios with JWT Bearer Interceptors Communicates with Express backend, attaches Firebase ID tokens automatically to headers.
Backend API Node.js, Express.js, Firebase Admin SDK RESTful endpoints, request logging, token authentication middleware, admin guards, game balance calculations.
Authentication & DB Firebase Auth, Cloud Firestore User identity management, real-time Firestore database persistence (users, runs, questions, rewards).

5. Security, Validation & Error Handling Pipeline

  • Authentication Guard: All protected API requests pass through `verifyToken.js` which cryptographically validates the Firebase ID token via `admin.auth().verifyIdToken()`.
  • Role Authorization Guard: Sensitive routes (`/api/admin/*`) execute `verifyAdmin.js` to ensure the requester possesses `role === 'admin'` in Firestore.
  • Input Sanitization: User profile updates (UPI ID, name, class) are sanitized to prevent injection attacks and invalid data types.
  • Centralized Logging & Error Diagnostics: The custom `logger.js` records request metrics, while `errorHandler.js` intercepts unhandled exceptions to return standard JSON error structures without leaking sensitive stack traces in production.
